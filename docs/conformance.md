# Conformance

Generated by `node scripts/gen-conformance-doc.mjs` from the test titles in `test/conformance/`. Do not edit by hand.
Each rule is a test that sends recorded or synthetic traffic through tokenyard in front of a mock provider and compares what the provider received and what the client got back.
C rules cover Anthropic Messages (Claude Code), R rules OpenAI Responses (Codex).
Bodies the gateway cannot price or read (an unpriced model, no model, JSON that does not parse) are forwarded unchanged only when no enforced budget level applies; under one they are refused before admit (security review A2, A5). C1, C11 and the parse-error rules therefore run with every budget in audit mode.
